## Map data — CC BY-SA 4.0

Map files under `src/maps/` (and the lobby catalogue `src/shared/Data/MapCatalog.luau`) are generated by `tools/pack-map.mjs` from
OpenFrontIO's `resources/maps`, which are licensed under the Creative Commons
Attribution-ShareAlike 4.0 license (https://creativecommons.org/licenses/by-sa/4.0/).

Attribution: **OpenFront**. The generated files re-encode the terrain
(zstd + base64) and scale nation coordinates for the Compact map size; they
are distributed under the same CC BY-SA 4.0 license.

## HUD icons — CC BY-SA 4.0

`src/shared/Data/Icons.luau` is generated by `tools/pack-icons.mjs`, which
rasterises SVG icons from OpenFrontIO's `resources/images` (CC BY-SA 4.0,
attribution: **OpenFront**) into 48×48 RGBA bitmaps. The generated file is
distributed under the same CC BY-SA 4.0 license.

## Other data from `resources/` — CC BY-SA 4.0

The following files are generated from OpenFrontIO's `resources/` directory
(CC BY-SA 4.0, attribution: **OpenFront**) and are distributed under the same
license:

- `src/shared/Data/Sprites.luau` — unit sprites (`tools/pack-sprites.mjs`, from `resources/atlases/unit-atlas.png`)
- `src/shared/Data/QuickChat.luau` — quick-chat phrases (`tools/pack-quickchat.mjs`)
- `src/server/Core/Data/TribeNameThemes.luau` — tribe names (`tools/pack-data.mjs`)
- `src/shared/Data/ThemeColors.luau` — theme colours (`tools/pack-colors.mjs`)
- `src/shared/Data/Flags.luau` — country flags (`tools/pack-flags.mjs`, from `resources/flags`)
- `src/shared/Data/Translations.luau` — UI translations (`tools/pack-lang.mjs`,
  from `resources/lang/*.json`, merged with this project's own translations in
  `tools/lang/`, which are released under the same license)
- `art/` — store icon and thumbnails (`tools/make-art.mjs`), rendered from
  `resources/maps` terrain and nation data

## Sound effects — CC BY-SA 4.0

The sound effects played by `src/client/Audio.luau` are OpenFrontIO's
`resources/sounds/effects/*.mp3` and `resources/sounds/ambience/*.mp3` (CC BY-SA 4.0, attribution: **OpenFront**),
uploaded unmodified as Roblox audio assets (IDs listed in `Audio.luau`). The
promo videos in `promo/` use the same effects and are distributed under the
same license.

## Music

The in-game music is **not** from OpenFront (its music is proprietary): the
tracks are from the APM Music library that Roblox licenses for use in Roblox
experiences (asset IDs and titles in `src/client/Audio.luau`).

## Not used

Nothing from OpenFrontIO's `proprietary/` directory (logos, fonts, sounds,
images — All Rights Reserved) is included in or used by this project.
